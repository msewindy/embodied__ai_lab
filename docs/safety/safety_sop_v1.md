## 一、红线原则 (Life-Saving Rules)

1. **二人规则**：任何中/高风险动态实验（如双足行走、机械臂高速挥舞），现场必须保证 **≥ 2 人** 在场。一人负责软件操作，另一人**必须手持该机器人的专属遥控器**，随时准备触发硬件掉电。
2. **严禁背对**：实验运行期间，任何人不得背对处于上电状态的机器人。
3. **物理隔离**：动态实验期间，除操作员外的所有人员必须退至安全围栏（Z-OP 区）外。

## 二、标准操作流程 (Standard Operating Procedure)

### 2.1 实验前准备 (Pre-Flight)
1. **场地检查**：清理 Z-DYN（动态实验区）内的杂物，确保机器人运动包络内无干涉。
2. **安全确认**：确认遥控器电量充足，且安全员已将手放在遥控器的掉电/失能开关上。
3. **流程登记**：确认已生成 `run_id` 并填写了实验计划。

### 2.2 上电与启动 (Power On)
1. 闭合机器人电池开关，系统上电。
2. 启动底层驱动桥节点，检查 `/perception` 话题是否有数据输出。
3. **大喊确认**：“准备启动，注意安全！”，确认安全员已就位。
4. 启动 `/skill` 和 `/plan` 节点，开始实验。

### 2.3 实验中监控 (Monitoring)
- 软件操作员需时刻关注 `/safety/global_state` 和控制台的 Warning 输出。
- 安全员需盯紧机器人的物理姿态，一旦发现异响、抽搐或偏离预定轨迹，**无需请示，立即拨动遥控器硬件急停开关，并拍下桌面的全局软件急停按钮**。

### 2.4 实验后收尾 (Post-Flight)
1. 软件下发驻车/归零指令。
2. 拨动遥控器切断电机使能，随后关闭机器人电池。
3. 导出并确认 `run_id` 对应的 rosbag 已成功落盘。

---

## 三、紧急情况处置 (Emergency Response)

### 3.1 机器人失控 / 碰撞
1. **第一动作 (Level 2)**：安全员立即拨动**遥控器硬件掉电开关**。
2. **第二动作 (Level 1)**：拍下最近的**全局软件急停按钮**（E1 或 E2），让系统记录故障时刻。
3. **第三动作 (Level 3)**：在确认机器人已倒地且无伤人风险后，上前拍下**机器人本体的物理急停按钮**，彻底断开电池。
4. **后续处理**：拍照记录现场，保留 `run_id` 数据，24 小时内召开复盘会，查明 Root Cause 前严禁再次上电。

### 3.2 电池起火 / 冒烟
1. **第一动作**：大声呼警，疏散室内人员。
2. **第二动作**：切断实验室总电源（防止其他设备受波及）。
3. **第三动作**：使用实验室配备的**干粉或二氧化碳灭火器**灭火（严禁用水）。
4. **后续处理**：拨打火警电话（若火势不可控），上报实验室负责人。

---

## 四、访客与观摩管理
- 访客进入实验室前，必须由 P3 或指定人员进行 2 分钟的安全宣导。
- 访客仅允许停留在 Z-OP（操作区）或 Z-STORE（存放区），严禁跨越安全围栏进入 Z-DYN 区。
