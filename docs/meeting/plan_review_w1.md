## 三、关键决策记录（2026-07-09 冻结）

1. **建设边界：** 框架期只做运行底座，不做 S1 等完整场景开发；首条 Pilot 为 **Franka 跨夹具工位**（框架 Go 后立项）。
2. **预算口径：** 框架 CAPEX 申请 **¥100,000**（包 A）；VR/灵巧手/多相机等 **~10 万研究外设移至 Pilot 项目池**，不进框架包（见 PLAN-BUDGET-02）。
3. **CAPEX 总盘：** 仍遵守 **≤20 万** 上限；Pilot 与储备另列占用剩余额度。
4. **软件基线：** 全实验室 **Ubuntu 24.04 + ROS2 Jazzy + Cyclone DDS**；Isaac Sim 6.0 / Lab 3.0（ws-02）。
5. **真机门禁：** 围栏+急停物理验收前，**禁止** Go2/人形等动态真机实验（E7 等）。
6. **团队编制：** **标准 4 人**（R1–R4）；R5 算法研究员按需；最低 3 人可启动但不作为工业 Pilot 目标配置。
7. **废止文档：** `方案.txt`、`方案_三人团队详细版.md` 已从仓库移除；以 L0 总体方案 + PLAN-BUDGET-02 为准。
