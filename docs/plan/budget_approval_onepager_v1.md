## 5. 首条工业 Pilot（框架 Go 后，另批）

- **场景：** Franka 跨夹具 pick-place 工位
- **预算参考：** ¥ 2～4 万（工位+治具+工位相机，不含算法人力）
- **指标：** 100 次试验成功率 ≥90%

---

## 6. 关键约束（审批附条件）

1. **真机动态实验门禁：** 围栏+急停验收前，禁止四足/人形全速动态实验。
2. **并发：** 同时 ≤2 台动态实验；动态区 ≥2 人在场。
3. **软件基线：** Ubuntu 24.04 + ROS2 Jazzy（已实施于 ws-01）。
4. **数据：** 全量 rosbag + run_id 追溯（平台已具备骨架）。
