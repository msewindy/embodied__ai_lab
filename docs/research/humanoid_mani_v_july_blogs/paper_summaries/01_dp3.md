# 论文解读：3D Diffusion Policy (DP3)

- **arXiv**：[2403.03954](https://arxiv.org/abs/2403.03954)
- **会议**：RSS 2024
- **作者**：Yanjie Ze, Gu Zhang, Kangning Zhang 等（Tsinghua / PKU 等）
- **PDF**：`papers/dp3_3d_diffusion_policy_2403.03954.pdf`
- **代码**：https://github.com/YanjieZe/3D-Diffusion-Policy

## 1. 问题与动机

2D 视觉模仿学习在视角、外观、空间位置变化时泛化差；现有 3D 方法常依赖精确标定与分割。DP3 提出用**稀疏点云 + 扩散策略**实现可泛化的视觉运动策略。

## 2. 方法

### 2.1 观测表征

- 单视角 RGB-D → 下采样稀疏点云（通常 1024 点）
- 轻量 **MLP Point Encoder** 提取紧凑 3D 特征（对比 PointNet++ 等更重方案）

### 2.2 策略网络

- **条件扩散模型**（Diffusion Policy 框架）：
  - 条件：3D 特征 + 机器人本体状态
  - 输出：未来 H 步动作序列（action chunk）
- 训练：对动作轨迹加噪，预测噪声 ε（DDPM）

### 2.3 Simple DP3

- 简化版编码器，推理更快，性能略降但仍优于 2D 基线

## 3. 实验

### 仿真（72 任务）

- 10 条示范即可在多数任务成功
- 相对 2D Diffusion Policy：**+24.2%** 相对提升

### 真机（4 任务）

- 每任务 40 条示范，**85%** 成功率
- 泛化：空间、视角、外观、实例变化
- 安全性：较少违反安全约束（对比 2D 基线）

## 4. 与 iDP3 关系

| 维度 | DP3 | iDP3 |
|------|-----|------|
| 点云坐标系 | 世界系（需标定） | 相机系（egocentric） |
| 点云处理 | 需分割桌面/背景 | 放大视野，无需分割 |
| 编码器 | MLP | 金字塔卷积编码器 |
| 目标平台 | 固定相机机械臂 | 人形/移动平台 |

iDP3 论文将 DP3 列为直接前身，改进点见 `02_idp3.md`。

## 5. 实现要点

- 观测：点云 + proprioception
- 动作：末端执行器 6-DoF 或关节空间
- 推理：DDIM 加速去噪（典型 10–20 步）
- 与 LeRobot / DexCap 等库有二次封装（专栏 LeRobot DP 一文）

## 6. 局限

- 仍依赖深度相机质量与点云密度
- 未处理动态场景与接触丰富任务的长时域推理
- 世界系版本对移动机器人标定负担大 → 催生 iDP3
