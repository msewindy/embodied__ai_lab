# 论文解读：EgoScale

- **arXiv**：[2602.16710](https://arxiv.org/abs/2602.16710)
- **作者**：Ruijie Zheng, Dantong Niu, Yuqi Xie, Linxi Fan, Danfei Xu 等
- **机构**：NVIDIA, UC Berkeley, UMD
- **PDF**：`papers/egoscale_2602.16710.pdf`
- **主页**：https://research.nvidia.com/labs/gear/egoscale/

## 1. 核心问题

人类视频能否在**大规模**下支持**高 DoF 灵巧操作**的迁移？还是仅适用于夹爪/低 DoF？

## 2. 主要发现

### 2.1 缩放定律

在 20,854 小时 egocentric 人类视频上预训练 VLA：

- 人类数据规模 ↑ → 验证损失 ↓（**对数线性**）
- 验证损失与**真机下游成功率强相关**
- 首次为机器人灵巧操作建立可预测的人类数据缩放规律

### 2.2 人类数据作为监督源

人类行为是可扩展的「物理智能」数据源，规模远超机器人遥操。

## 3. 三阶段训练管线

```
Stage 1: 人类预训练 (20,854 h)
    手腕相对运动 + 重定向 22-DoF 灵巧手动作
         ↓
Stage 2: 人机对齐中期训练 (少量)
    同场景、同视角、配对人类/机器人演示
    MANUS 手套 + Vive 追踪
         ↓
Stage 3: 任务后训练 / one-shot
    极少机器人示范微调
```

### 3.1 动作表示

- 人类：相对腕部 3D 运动 + retargeted 灵巧手关节
- 机器人：embodiment-specific MLP 适配器映射到共享 latent 空间
- VLM + DiT **跨形态共享**（类似 GR00T）

### 3.2 对齐数据

- 344 种桌面任务
- 人类与遥操机器人同相机配置
- MANUS：每手 25 关节变换；机器人侧同 setup

## 4. 实验结果

| 指标 | 结果 |
|------|------|
| vs 无预训练 | 平均成功率 **+54%**（22-DoF Sharpa 手） |
| One-shot 叠衬衫 | **88%** |
| Unitree G1 三指手 | **+30%** 绝对提升 |
| 数据规模 1k→20k 小时 | 任务完成率 **>2×**（NVIDIA 对外表述） |

## 5. 与 GR00T N1.7 关系

- EgoScale 是人类视频预训练框架
- **GR00T N1.7** 将 EgoScale 作为核心预训练阶段
- N1.7 升级 VLM 为 Cosmos-Reason2-2B，并引入相对 EE 动作空间

## 6. 工程状态（截至专栏）

- 论文项目页已公开；代码截至 2026-03 专栏称尚未完全开源
- 模型权重通过 Isaac GR00T / HuggingFace 渠道发布（N1.7）

## 7. 理论意义

- 将 NLP/CV 的 scaling law 叙事扩展到**灵巧机器人操作**
- 支持投资方向：人类视频标注 pipeline > 纯机器人遥操扩规模

## 8. 局限

- 中期训练仍需精心对齐的人机配对数据
- 极端接触力控、柔性物体仍困难
- 计算：20k 小时预训练成本极高

## 9. 对本实验室

- 若无法复现全规模预训练：**直接用 N1.7 权重**获得 EgoScale 收益
- 可自建小规模人类视频 + 中期对齐试验验证缩放趋势
- MANUS/Vive 方案可参考用于精密手部位姿标注
