# 论文解读：HIL-DAFT

- **标题**：Dual-Actor Fine-Tuning of VLA Models: A Talk-and-Tweak Human-in-the-Loop Approach
- **arXiv**：[2509.13774](https://arxiv.org/abs/2509.13774)
- **作者**：Piaopiao Jin, Qi Wang, Guokang Sun, Ziwen Cai, Pinjia He, Yangwei You
- **机构**：小米、香港城市大学
- **PDF**：`papers/hil_daft_2509.13774.pdf`
- **项目**：https://sites.google.com/view/hil-daft/

## 1. 问题

| 挑战 | 说明 |
|------|------|
| 样本效率 | 真机 RL 代价高 |
| 安全性 | 在线探索风险 |
| 语义纠正 | 传统 HIL 仅物理干预，难转化为可学习信号 |
| 多任务 | 既有 HIL-RFT 多针对单任务 |

## 2. 方法概览

### 2.1 双 Actor 结构

```
观测 + 语言
    ↓
主 Actor（一致性/扩散策略）→ 任务通用动作
    ↓ 潜在噪声空间
精细化 Actor → 语言条件细粒度调整
```

- 主 Actor：标准 VLA 动作生成，$\pi_\theta(a|s, \ell)$
- 精细化 Actor：在噪声 $z$ 上条件于**精炼语言指令** $\ell_{refine}$

### 2.2 Talk-and-Tweak

| 步骤 | 内容 |
|------|------|
| 物理干预 | 操作员 SpaceMouse 纠正末端位姿 |
| 语义映射 | 规则/模板将纠正转为语言（「向左」「下降一点」） |
| 双路学习 | 主 Actor 学纠正后轨迹；精细化 Actor 学语言→调整映射 |

生成 **talk-and-tweak 数据集**用于精细化策略监督。

### 2.3 训练阶段

1. **离线预热**：示范 + 历史纠正
2. **在线 HIL RL**：人在环 rollout，持续收集纠正对

动作头基于**一致性模型**（单步去噪蒸馏）而非完整多步扩散，利于实时控制。

## 3. 任务：螺栓装配

三阶段子任务：

1. **Stand**：将躺倒螺栓竖立
2. **Pick**：稳定抓取
3. **Insert**：插入部分遮挡螺柱（毫米级对齐）

长时域变体：12 步连续重复三阶段。

## 4. 实验结果

| 指标 | HIL-DAFT |
|------|----------|
| 三子任务成功率 | **100%**（101 分钟在线微调） |
| 12 步长时域 | **50%** 完整成功 |
| vs HG-Dagger | 更高成功率 + 更短 episode |
| vs HIL-ConRFT | 多任务显著更优 |
| vs DSRL | 在线数据利用更高效 |
| 双机器人 | 训练效率 **2×** |

## 5. 与相关 work

| 方法 | 关系 |
|------|------|
| HIL-SERL | 单任务 RL + 纠正 |
| ConRFT | 离线+在线 RL，扁平优化 |
| DSRL | 扩散策略 latent 噪声引导 |
| VLA-RL | 纯 RL 微调 VLA，无结构化精细化 |

HIL-DAFT 独特点：**语言化精细化 + 双 Actor 分工**

## 6. 适用场景

- 已有预训练 VLA，需精密装配/插拔类任务
- 可接受人在线 1–2 小时监督
- 双足人形（论文强调相对轮式/臂较少见）

## 7. 局限

- 规则化语言映射可能覆盖不全纠正类型
- 长时域 50% 仍有提升空间
- 依赖特定 VLA + 一致性动作头实现

## 8. 对本实验室

- 若部署 GR00T 后精密任务失败率高，可借鉴 talk-and-tweak 收集精炼数据
- 可与现有安全 SOP 结合：人仅在安全状态下介入纠正
- 螺栓装配与实验室「线缆插拔、智能装配」场景高度相关
