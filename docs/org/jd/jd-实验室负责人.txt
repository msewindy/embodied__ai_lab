岗位概述
具身智能实验室的第一负责人，对实验室「从 0 到 1 建设、安全合规运营、工业 Pilot 交付、团队目标达成」负总责。该岗位兼具战略规划、建设项目管理、技术架构决策与跨部门协调职能，是连接公司战略、预算审批、工业客户需求与实验室日常运行的核心枢纽。

本实验室当前阶段的核心目标不是单点 Demo，而是建设一套可安全运营、可纳管设备、可接项目的实验室运行框架，并在框架就绪后推动首条工业场景 Pilot 落地。

岗位职责
1. 实验室战略与建设规划

制定实验室中长期建设路线图，明确「框架期 → Pilot 期 → 稳定运营期」分阶段目标
主导《实验室运行框架建设总体方案》、WBS、里程碑、Go/No-Go 门禁体系的制定与迭代
定义实验室建设边界：区分「实验室公共底座」与「项目专用工位/设备」，避免范围蔓延
结合工业落地目标，选定首条 Anchor Pilot（如 Franka 跨夹具工位、精密装配工位），输出任务书与验收指标
2. 预算、采购与项目管理

统筹实验室 CAPEX / OPEX 预算编制、报批与执行跟踪（框架包、Pilot 包、人力包分开口径）
审批 P0/P1 级采购 BOM，协调采购节奏与施工窗口，控制成本与预备金使用
组织 W1/W4/W10/W16 等关键节点评审，对阶段交付物签字负责
识别并管理项目风险：进度延误、安全合规、设备不可用、范围蔓延、人力单点等
3. 技术架构与标准制定

审定实验室六层架构（空间/硬件/软件/数据/流水线/组织）边界与技术契约
主导或审定统一消息接口、run_id 规范、版本矩阵、Driver Bridge 成熟度、PreFlight 门禁等核心标准
在「框架优先」与「Pilot 交付」之间做技术取舍，确保平台可扩展、项目可接入
参与重大技术方案评审（sim2real 路线、VLA/IL 技术选型、工业工位方案），不做日常编码主力
4. 团队组建与管理

负责 R2/R3/R4（及按需 R5）的招聘需求定义、面试评估与到岗规划
建立 RACI、站会/复盘/变更评审（CR）机制，保障小团队高效协作
设定各岗位 KPI 与阶段性交付目标，开展绩效评估与人员备份规划
营造「文档即交付、安全底线不可妥协、工业指标导向」的团队文化
5. 安全合规与对外接口

对实验室安全 SOP、急停链路、双人操作规则、事故响应机制负最终责任
组织安全演练、框架验收、交叉实验验证，确保「可安全运营」先于「可演示」
作为实验室对外的第一接口：对接公司管理层、工业客户/工厂、合作方与供应商
将外部工业需求转化为可执行的 Pilot 范围、指标与排期，避免需求直接冲击平台底座
6. 成果交付与价值呈现

推动框架 Go 与首条 Pilot 的里程碑交付，形成可汇报、可验收、可复制的成果包
组织技术白皮书、Pilot 报告、对外 Demo 与汇报材料
协同算法研究员规划论文/专利/开源等技术产出节奏，平衡研究与交付
为实验室下一阶段扩展（第二 Pilot、工业集成、增编）提供决策依据
任职要求
学历与经验

硕士及以上学历，机器人、自动化、人工智能、计算机、机械电子等相关专业；本科优秀者可放宽
5 年及以上机器人、具身智能、工业自动化或实验室/研发中心建设相关经验
至少 1 次 0→1 主导经验：实验室搭建、机器人产品平台、工业 Pilot 或跨团队技术项目
