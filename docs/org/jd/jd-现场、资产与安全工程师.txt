岗位概述
负责具身智能实验室的物理世界运营：场地与安全设施、设备资产台账、点检维护、现场实验支持、安全 SOP 执行与应急演练。
本岗位是兼具机器人现场调试 + 实验室安全管理 + 资产运维的复合型工程岗位。

岗位职责
1. 场地、安全设施与施工配合
负责实验室功能分区（Z-DYN/Z-OP/Z-MAINT 等）落地，参与平面图/CAD 施工图绘制与现场实测
主导或配合安全围栏、急停控制箱、地面标识、监控摄像头、消防急救器材等安装验收
配合弱电/网络施工，确认急停信号接入ROS2、监控覆盖、动线与疏散路线合理
维护软硬安全接口（HSI）：软件急停、遥控器硬件阻断、本体物理断电三级机制的现场可执行性
组织动态实验前的现场安全检查（围栏到位、急停可用、人员到位）

2. 安全制度与应急管理
编写、维护并推动执行《实验室安全操作规程（SOP）》、访客管理、事故分级与响应流程
组织新员工/协作人员安全培训，落实「动态实验 ≥2 人在场、一人持遥控器」等强制规则
策划并执行应急演练（急停、通信中断、设备异常等），形成演练记录与改进项
对实验现场进行日常安全巡查，发现隐患及时叫停实验并上报
参与事故调查与复盘，更新 SOP 与 PreFlight 检查项

3. 资产台账与运维管理
建立并维护实验室资产台账（机器人、终端、基础设施、安全设施、备件、传感器等）
负责设备 SN、固件版本、责任人、状态（ready/limited/blocked/maintenance）等字段的准确更新
执行日检/周检/月检制度，输出点检记录、维护日志与备件补货建议
管理备件最小库存（电池、夹爪指尖、线缆套件、易耗品等），保障实验连续性
协调设备故障工单：发现 → 停用 → 维修 → 复测 → 台账更新 → 复盘通报

4. 机器人现场接入与实验支持
负责机器人 onboard 环境准备（Ubuntu/ROS2、网络、SDK、Driver Bridge 部署配合）
参与真机 bringup（如 Go2 E4/E7）、Franka/人形/四足等设备的上电、零点、基础功能验证
协助应用工程师完成手眼标定、相机安装、工位治具定位、现场线缆与安全走线
实验日现场值守：按 SOP 执行 Pre-check、记录 run_id、监控设备状态与异常情况
实验后推动设备归零、充电、断电、数据归档确认

5. 工业工位与 Pilot 现场落地
参与工业 Pilot 工位的现场施工配合：操作台、治具安装、相机/光源固定、安全边界确认
根据 Pilot 任务书维护工位级安全要求（速度上限、禁入区、工装状态检查）
采集并质检实验数据（完整性、传感器在线、异常标记），配合平台与应用团队复盘
输出现场实施报告、工位验收记录、演示保障方案

6. 文档与协作
维护 layout、estop 布线图、设备 capability 状态、维护 policy 等 L3 运维文档
参与变更评审与实验复盘，更新台账与 meeting 纪要
协作完成物理安全与软件 SafetyState 链路联调
协作完成真机/工位调试，承担现场安全员角色

任职要求
学历与经验
大专及以上学历，机器人、自动化、机电一体化、机械电子、安全工程等相关专业
2 年及以上机器人现场、实验室、自动化产线或设备运维相关经验
有真实机器人（机械臂、AGV/AMR、四足/人形等）现场调试或运维经验者优先

技术能力
熟悉机器人现场基础操作：上电、零点、急停、基础示教/调试、简单故障排查
具备弱电与现场施工配合能力：围栏/急停/监控/走线/标识安装，能读简单电气接线图
熟悉实验室或工厂现场安全管理基本要求，具备风险识别与现场处置意识
能使用 Excel/台账系统/文档工具维护资产与点检记录，细致、可追溯
具备基本 Linux/网络常识（IP、ping、SSH、ROS2 节点是否在线），能与 R2/R4 有效协作
有 Franka、UR、ABB、宇树、智元等至少一类机器人现场经验
有 EHS、实验室安全员、设备管理员相关经验或证书（注册安全工程师、电工证等）
有 ChArUco/AprilTag 标定、相机/夹爪安装、工位治具调试经验
有 ROS/ROS2 基础认知，能理解 bringup、SafetyState、run_context 等现场含义
有工业客户现场交付、演示保障、访客接待经验

加分项

动手能力强，能在实验室现场长时间工作并处理突发问题
细致耐心，台账/点检/记录不敷衍，适合「底线型」岗位
沟通协作良好，能与算法/平台/应用不同背景同事配合
持有电工操作证、注册安全工程师、消防设施操作员等资质
有黑灯实验室、自动化实验室、机器人测试场建设或运维经验
有工业铝型材围栏、急停回路、PoE 监控等弱电项目实施经验
有宇树/Franka/人形机器人售后或现场交付背景
具备一定的 CAD/Visio 绘图能力，能独立输出场地与点位图
