岗位一：平台与基础设施工程师
岗位概述
负责具身智能实验室的共用软件平台、网络算力、数据基础设施与 ROS2 中间件建设，是实验室「运行框架」的技术底座负责人。该岗位需保障所有实验具备可复现、可追溯、可部署的工程环境，支撑 sim2real 闭环与工业 Pilot 项目接入。

岗位职责
1. 实验室基础设施与网络
负责实验室专网、万兆交换、NAS 存储、UPS 等基础设施的规划、部署与运维
设计并维护机器人/工作站/onboard 节点的网络拓扑、静态 IP、VLAN 隔离与 ROS2 DDS 通信策略
评估并保障多机并发实验下的数据吞吐（rosbag 录制、checkpoint 同步、跨节点文件归档）
编写网络与存储验收文档，配合现场工程师完成弱电施工联调

2. 共用软件平台负责实验室平台代码的架构维护
实现并维护 Isaac Sim/Lab 训练任务接入、Policy 同步、跨机部署等 Pipeline A/C 能力
维护 Driver Bridge 框架、设备能力矩阵、成熟度相关工程规范
推动平台模块实现与集成，制定模块优先级与验收标准

3. ROS2 中间件与系统集
负责 ROS2 Jazzy 基线、消息接口（msg/srv/action）、launch 体系、Cyclone DDS 等中间件统一
开发/维护多形态机器人（机械臂、四足、人形等）的驱动桥接、安全协调、限幅与 run_context 广播
搭建低延迟、可观测的 ROS2 通信链路，解决 QoS、跨机 Topic、时间同步等工程问题
配合应用工程师完成真机 bringup、sim2real 部署与联调

4. 数据治理与 DevOps
制定并落地 run_id 规范、实验目录结构、metadata 索引、冷热数据分层归档策略
建设 CI/CD（lint、配置校验、接口兼容检查、冒烟测试），保障团队并行开发质量
维护版本矩阵（OS / ROS2 / Python / Isaac / PyTorch），执行变更评审（CR）与回归验证
编写环境安装清单、check_env 脚本、onboarding 文档，降低新人上手成本

5. 跨团队协作
与实验室负责人对齐平台路线图与里程碑，参与框架项目门禁评审
与现场安全工程师协作，实现软件急停、SafetyState 广播、实验 PreFlight 门禁
为算法研究员提供训练环境、数据接口、模型部署通道与性能 profiling 支持

任职要求
1.学历与经验：
本科及以上学历，计算机、软件工程、自动化、机器人等相关专业
3 年及以上 Linux 服务器/机器人中间件/平台工程经验
有真实机器人项目落地经验（机械臂、移动机器人、人形/四足至少一类）

2.技术能力：
精通 Python，熟悉 C++，具备良好的代码规范与文档习惯
熟练掌握 ROS2（Humble/Jazzy 均可），理解 DDS、launch、QoS、rosbag2 等核心机制
熟悉 Linux 系统管理、Shell、Docker、Git、网络基础（TCP/IP、VLAN、组播/DDS 常见问题）
具备软件架构能力，能设计模块化、可测试、可扩展的平台服务（非 Demo 级脚本堆叠）
理解实验数据治理：run 生命周期、版本 pinning、日志追溯、artifact 管理
有 NAS/分布式存储、rsync/NFS、数据归档自动化经验
有 Isaac Sim / Isaac Lab / MuJoCo 等仿真平台接入经验
有 Cyclone DDS 调优、跨机 ROS2 通信、PTP/NTP 时间同步经验
有 SQLite/轻量索引服务、CLI 工具链、GitHub Actions/GitLab CI 实践经验
了解 LeRobot、ALOHA 类数据框架，或 teleop → train → deploy 工程闭环

加分项
工程化思维强，重视稳定性、可维护性、可交接性
能在团队中独立负责一条技术主线，主动推进阻塞项
沟通清晰，能把技术决策沉淀为可执行的规范文档
有 MoveIt2、ros2_control、Nav2 等常用 ROS2 生态组件经验
有工业现场网络（防火墙、弱电、监控 RTSP）实施经验
有开源机器人项目贡献或技术博客/内部分享
