岗位概述
负责将具身智能能力落地到真实机器人与工业验证工位。工作重点包括 sim2real 迁移、Franka/四足等设备真机调试、工业 pick-place/装配工位联调，以及与平台工程师协作完成策略部署、标定、评测与迭代。

岗位职责
1. Sim2Real 与真机部署
负责仿真环境（Isaac Sim/Lab、MuJoCo、Gazebo 等）到真机的策略迁移与部署闭环
开展系统辨识（SysID）、域随机化（DR）、残差适配等 sim2real 工程实践，缩小仿真与真机 gap
在真机上部署模仿学习/强化学习策略（如 ACT、Diffusion Policy、PPO 等），并完成安全包装（限幅、平滑、异常降级）
维护设备 bringup 流程、驱动联调、传感器接入与基础 health check

2. 工业工位应用开发
主导 Franka 工业工位（跨夹具 pick-place、视觉定位、节拍优化）的方案落地与现场调试
参与工位治具、相机安装位、光源布局、成功检测等场景相关工程设计与联调
定义并追踪工业向 KPI：任务成功率、节拍时间、人工接管率、复现周期等
输出工位调试报告、评测数据与对外演示脚本，支撑工厂/客户 Pilot 汇报

3. 机器人控制与系统集成
负责机械臂/移动机器人的运动学、轨迹规划、基础力控/阻抗控制调试
使用 ROS2 完成感知—规划—执行链路集成，对接平台规范
完成手眼标定、相机外参、TCP 标定等现场标定工作，并归档至实验室配置库
与现场安全工程师协作，遵守 SOP，保障动态实验双人规则与急停链路有效

4. 数据采集与评测
搭建并执行 teleop / 示教 / 重复试验等数据采集流程，保障 obs-action 对齐与数据可训练性
设计 benchmark 实验，输出成功率、延迟、失败模式分析
配合算法研究员进行真机微调、消融实验与 A/B 对比
维护设备最小任务清单并持续更新基线

5. 文档与知识沉淀
编写 sim2real 部署手册、工位操作 SOP、故障排查指南
参与项目复盘，沉淀可复用工位模板与配置包

任职要求
学历与经验
本科及以上学历，机器人、自动化、控制工程、计算机、机械电子等相关专业
3 年及以上机器人应用开发或运动控制相关经验

技术能力
精通 Python，熟悉 C++ 者优先；熟练使用 PyTorch

扎实的机器人学基础：运动学、动力学、坐标变换、轨迹规划
熟悉至少一种机械臂或移动机器人生态（Franka、UR、宇树、AgileX 等）
理解 sim2real 核心问题：动力学差异、视觉 domain gap、控制延迟、接触不确定性
具备现场调试能力：示波器/日志分析、标定、治具微调、问题定位
有 Franka / 工业机械臂 pick-place、换夹爪、视觉伺服项目经验
有模仿学习策略（BC、ACT、Diffusion Policy）真机部署经验
熟悉 MoveIt2、ros2_control、RealSense 等常用工具链
有 Isaac Sim/Lab、MuJoCo 仿真验证经验
了解 LeRobot、ALOHA、Open-TeleVision 等数采/遥操框架
